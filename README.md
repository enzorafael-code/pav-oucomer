# Pavê ou Comer 🍰

## Descrição
Aplicativo mobile de delivery e encomendas especializado em pavês artesanais (tradicionais e frutados). A aplicação permite visualizar ofertas especiais, navegar por categorias, explorar o cardápio com preços e adicionar itens ao carrinho de compras de forma simples e intuitiva.

## Funcionalidades
- Exibição de banner promocional com ofertas em destaque.
- Navegação por categorias de pavês.
- Catálogo de produtos com nome, imagem/ícone, preço e botão para adicionar ao carrinho.
- Contador dinâmico de itens adicionados ao carrinho.

## Tecnologias Utilizadas
- React Native
- Expo / Expo Router
- TypeScript
- NativeWind (Tailwind CSS)
