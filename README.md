🍰 Pavê ou Comer
📝 Descrição
O Pavê ou Comer é uma aplicação mobile de delivery especializada em pavês artesanais, doces trufados e bebidas. O aplicativo oferece um cardápio digital interativo com visualização de produtos, ofertas especiais e um carrinho de compras dinâmico para montagem e finalização de pedidos.

🎯 Objetivo
Facilitar o processo de escolha e encomenda de sobremesas e bebidas de forma rápida, intuitiva e visualmente agradável pelo celular, resolvendo a dificuldade de clientes consultarem sabores disponíveis, combos promocionais e o valor total do pedido em tempo real antes de finalizar a compra.

🚀 Tecnologias Utilizadas
React Native

Expo / Expo Router

TypeScript

NativeWind (Tailwind CSS)

Git & GitHub

⚙️ Funcionalidades
✓ Visualização de categorias e produtos populares com imagens e preços

✓ Banner de oferta especial com adição rápida ao carrinho

✓ Adição de produtos ao carrinho

✓ Remoção individual de itens do carrinho

✓ Contagem automática da quantidade de itens no carrinho

✓ Cálculo dinâmico do valor total da compra

✓ Finalização de pedido com confirmação na tela

▶️ Como Executar o Projeto
Clone o repositório: git clone COLE_AQUI_O_LINK_DO_SEU_REPOSITORIO

Acesse a pasta do projeto: cd pavêoucomer

Instale as dependências: npm install

Inicie o servidor de desenvolvimento do Expo: npx expo start

Escaneie o QR Code exibido no terminal utilizando o aplicativo Expo Go (Android/iOS) ou pressione a para abrir no emulador Android / w para abrir no navegador.
